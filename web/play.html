Play Java games online in your browser

JavaPlay is a free J2ME emulator that runs old Java (.jar) phone games right on this page: no download, no plug-in and no sign-up. Its own JavaScript engine runs games made for MIDP 1.0/2.0 phones and the Nokia UI API.

How to play a Java game online

  1. Open the Free games tab above and tap a game. 163 openly licensed Java games are ready to play.
  2. Or tap + (or drop the file on the game list above) to add your own .jar game. Pick the .jar file, not the .jad.
  3. Screen size, rotation and controls are set for you. You can change them from the ☰ menu while playing.

Controls

Use the phone keypad on screen, tap the game screen in touch games, or use your keyboard: arrows to move, Enter = OK, F1 / F2 = soft keys, 0–9, * and #, Esc = menu. You can change the keys in Menu → Controls.

Which Java games work?

2D games made for MIDP 1.0/2.0 and Nokia phones, at screen sizes from 128×128 up to 480×800. 3D games (M3G, Mascot Capsule) and online features are not supported yet. Saves and high scores stay in this browser. Use a recent Chrome or Edge.
